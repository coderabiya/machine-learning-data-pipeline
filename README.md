# 🤖 Machine Learning Pipeline – Data Processing & Model Building

This repository demonstrates a complete machine learning workflow, covering data preprocessing, feature engineering, and model building using Python.

The project is structured into multiple tasks, each focusing on a key step in the machine learning pipeline.

---

## 📌 Project Overview

The objective of this project is to build a structured machine learning pipeline by performing:

- Data cleaning and preprocessing  
- Handling missing values  
- Feature selection  
- Data transformation  
- Model training and evaluation  

---

## 📂 Project Structure

├── cleaned_sample_data.csv        # Processed dataset ├── task1_data_prepration.py       # Data cleaning and preparation ├── task2_data_processing.py       # Data preprocessing and transformation ├── task3_feature_selection.py     # Feature engineering and selection ├── task4_model_building.py        # Model training and evaluation └── README.md                     # Project documentation

---

## ⚙️ Tasks Explanation

### 🔹 Task 1: Data Preparation
- Loaded dataset using Pandas  
- Cleaned raw data  
- Handled missing values  
- Saved cleaned dataset to CSV  

---

### 🔹 Task 2: Data Processing
- Performed data transformation  
- Prepared dataset for machine learning  
- Standardized and formatted data  

---

### 🔹 Task 3: Feature Selection
- Selected relevant features  
- Removed unnecessary columns  
- Improved model input quality  

---

### 🔹 Task 4: Model Building
- Split dataset into training and testing sets  
- Trained machine learning model  
- Evaluated performance using metrics
